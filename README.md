# LLM RAG Chatbot

This project demonstrates a simple Retrieval-Augmented Generation (RAG) chatbot using:

- Hugging Face Transformers
- LangChain
- FAISS vector database
- Streamlit for UI

This repo will contain:
- A Colab notebook for embeddings + RAG pipeline
- A basic Streamlit demo chatbot
- Example prompt templates
- Embedding + vector store examples

More files will be added soon.
